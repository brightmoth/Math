# Algebra Basics

## 1. Variables and Expressions

- Variable: a letter that represents an unknown value. Example: `x`, `y`, `a`
- Mathematical expression: a combination of numbers, variables, and operations. Example: `3x + 5`, `2y - 7`, `x^2 + 4x`

### Example
- `x + 4` is an expression.
- `3x - 2 = 10` is an equation because it contains an equals sign.

## 2. Equations and Inequalities

- Equation: two expressions joined by an equals sign.
  - Example: `2x + 3 = 11`
- Inequality: two expressions compared using `<`, `>`, `<=`, or `>=`.
  - Example: `x + 5 > 9`
  - Example: `3x <= 12`

### Equation walkthrough: solving `2x + 3 = 11`

1. Subtract 3 from both sides:
   `2x + 3 - 3 = 11 - 3`
   `2x = 8`
2. Divide both sides by 2:
   `2x / 2 = 8 / 2`
   `x = 4`
3. Check the solution:
   `2(4) + 3 = 8 + 3 = 11`

So, the solution is `x = 4`.

### Inequality example
Solve `x + 5 > 9`.

1. Subtract 5 from both sides:
   `x + 5 - 5 > 9 - 5`
   `x > 4`

This means any value greater than 4 works.

## 3. Like Terms and Unlike Terms

- Like terms: terms with the same variable and same exponent.
  - Example: `3x` and `7x`
  - Example: `5x^2` and `2x^2`
- Unlike terms: terms that do not match in variable or exponent.
  - Example: `3x` and `3y`
  - Example: `2x^2` and `2x`

### Examples
- `4x + 2x = 6x`
- `5y^2 - 2y^2 = 3y^2`
- `3x + 2y` cannot be combined because they are unlike terms.

## 4. Number Classification

1. Natural numbers: `1, 2, 3, 4, 5, ...`
2. Whole numbers: `0, 1, 2, 3, 4, 5, ...`
3. Integers: `..., -3, -2, -1, 0, 1, 2, 3, ...`
4. Rational numbers: any number that can be written as a fraction, such as `1/2`, `3/4`, or `0.75`
5. Irrational numbers: decimals that continue without repeating in a pattern, such as `pi` (`3.14159...`)

## 5. Working with Signed Numbers

Rules:
- If signs are different, the answer is negative.
- If signs are the same, the answer is positive.

Examples:
- `11 + (-8) = 3`
- `-5 + 4 = -1`
- `3 - (-6) = 9`
- `6 * (-2) = -12`
- `-8 / -2 = 4`
- `3 * (-2) * (-4) = 24`

### Walkthrough of a signed-number problem
Solve `-7 + 10`.

- The signs are different, so subtract the smaller absolute value from the larger:
  `10 - 7 = 3`
- Since 10 is larger and positive, the answer is positive:
  `-7 + 10 = 3`

## 6. Fractions

- Numerator: the top number of a fraction
- Denominator: the bottom number of a fraction

### Types of fractions
- Proper fraction: numerator is smaller than denominator. Example: `5/6`, `2/3`, `1/2`
- Improper fraction: numerator is greater than or equal to denominator. Example: `10/3`, `8/2`
- Mixed number: a whole number and a fraction. Example: `2 2/3`

### Converting mixed numbers to improper fractions
Convert `2 2/3` to an improper fraction.

1. Multiply the whole number by the denominator:
   `2 * 3 = 6`
2. Add the numerator:
   `6 + 2 = 8`
3. Keep the same denominator:
   `2 2/3 = 8/3`

### Converting improper fractions to mixed numbers
Convert `16/5` to a mixed number.

1. Divide 16 by 5:
   `16 ÷ 5 = 3` remainder `1`
2. The quotient is the whole number and the remainder becomes the numerator:
   `3 1/5`

### Adding and subtracting fractions
Example: `1/6 + 2/4`

1. Find a common denominator. The least common denominator of 6 and 4 is 12.
2. Rewrite each fraction:
   - `1/6 = 2/12`
   - `2/4 = 6/12`
3. Add the numerators:
   `2/12 + 6/12 = 8/12`
4. Simplify:
   `8/12 = 2/3`

So, `1/6 + 2/4 = 2/3`.

### Multiplying and dividing fractions
- Multiplying: `3/5 * 4/7 = 12/35`
- Dividing: `3/5 ÷ 8/9 = 3/5 * 9/8 = 27/40`

### Fraction walkthrough
Solve `2/3 + 1/6`.

1. Common denominator: `6`
2. Rewrite `2/3` as `4/6`
3. Add: `4/6 + 1/6 = 5/6`

Final answer: `5/6`

## 7. Exponents

An exponent tells how many times a number or variable is multiplied by itself.

- `4^5 = 4 * 4 * 4 * 4 * 4`
- `x^2` means `x * x`

### Exponent rules
- `x^2 * x^4 = x^6`
- `x^9 / x^4 = x^5`
- `x^2y^3 * xy^4 = x^3y^7`
- `(4xy^2)^2 = 16x^2y^4`
- `2x(3x^2y^3)^2 = 54x^5y^6`
- `2^-2 = 1/4 = 0.25`
- `(2x / y^2)^-3 = y^6 / 8x^3`

### Example walkthrough
Simplify `(3x^2)^3`.

1. Raise each part inside the parentheses to the third power:
   `(3x^2)^3 = 3^3 * (x^2)^3`
2. Evaluate `3^3 = 27`
3. Multiply exponents: `(x^2)^3 = x^6`

Final result: `27x^6`

## 8. Order of Operations

Use the order:
1. Parentheses
2. Exponents
3. Multiplication and division from left to right
4. Addition and subtraction from left to right

Mnemonic: PEMDAS

### Example
Solve `8 + 3(5 - 2)^2`.

1. Parentheses: `5 - 2 = 3`
2. Exponents: `3^2 = 9`
3. Multiplication: `3 * 9 = 27`
4. Addition: `8 + 27 = 35`

Answer: `35`

## 9. Quick Summary

- A variable is a letter that stands for an unknown value.
- An expression has numbers, variables, and operations.
- An equation has an equals sign.
- An inequality compares two values using `<`, `>`, `<=`, or `>=`.
- Like terms can be combined; unlike terms cannot.
- Always follow the order of operations to simplify expressions correctly.
